# Todo API

A simple Todo REST API built with FastAPI as a learning project.

## Features

- Create a todo
- Get all todos
- Get a todo by ID
- Update a todo
- Delete a todo

## Tech Stack

- Python
- FastAPI
- Pydantic
- Uvicorn

## Storage

Currently uses in-memory Python data structures.
Database integration will be added in a later version.

## Run Locally

Clone the repository and navigate into the project:

```bash
cd fastapi-todo-api
```
